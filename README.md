# Curve Video Codec

ترميز فيديو منحني زمني:
- I = قاموس ألوان + منحنيات حقيقية + حجوم
- P/B = أوامر على المنحنيات
- مقارنة عادلة مع AV1

## الاستخدام على GitHub Actions

1. اذهب إلى تبويب **Actions**
2. اختر **"اختبار الترميز المنحني على فيديو حقيقي"**
3. اضغط **Run workflow**
4. أدخل:
   - رابط الفيديو المباشر
   - عدد الإطارات (مثل 30)
   - الدقة (مثل 480)
   - حجم القاموس (16)
   - دقة المنحنيات (1.5)
   - CRF (30)
   - preset (8)
5. انتظر النتيجة وستجد ملف `curve-results` في الـ Artifacts

## النتائج

النتائج تظهر في `results/results.json`:
- `size_curve_rep`: حجم التمثيل المنحني الكلي
- `size_av1`: حجم AV1 المرجعي
- `size_reduction_percent`: نسبة التوفير
- `avg_psnr`: متوسط جودة إعادة البناء
- `avg_ssim`: متوسط التشابه البصري
